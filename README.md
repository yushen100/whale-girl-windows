# 🐋 微信鲸鲸 · Windows 一键部署版

这是本机 Windows 微信鲸鲸项目的脱敏公开版，不是 ECS/Linux 版本。保留网页聊天、微信桥接、分群记忆、白名单、图像处理、查证与分群复盘相关代码。

## 下载与启动

请在右侧 **[Releases](https://github.com/yushen100/whale-girl-windows/releases/latest)** 下载 Windows 完整包。GitHub 的 **Code → Download ZIP** 是源码，不含便携运行时。

1. 将完整包解压到普通本地目录，推荐 `D:\WhaleGirl`。无需管理员权限、无需另装 Node 或 Python。
2. 在桌面微信里登录自己的账号。首次收发需要你完成微信的扫码/手机确认。
3. 双击 **`一键部署鲸鲸.cmd`**。首次窗口填写自己的模型接口、模型名称、API Key、机器人称呼和允许回复的群完整名称，然后点击“保存并启动”。以后双击同一入口即可。
4. 打开 `http://127.0.0.1:8787/` 设置与聊天，`/debug` 查看运行状态。

完整包包含 Node、Python、微信自动化依赖、OCR 依赖和模型、FFmpeg，以及界面和词库资源。模型服务需要使用者自行配置；本项目不提供他人的额度、账号或反代凭据。

## 完整性与附件清单

请等附件上传完整后再下载，不要下载不完整的包。本次每套都是单个 ZIP，没有分卷。

| 附件 | 用途 |
|---|---|
| `whale-girl-windows-3.53.1-full.zip` | Windows x64 完整运行包，必须完整下载 |
| `whale-girl-windows-3.53.1-source.zip` | 脱敏源码包，供开发者使用 |
| `SHA256SUMS.txt` | 上述两套 ZIP 的字节大小与 SHA-256 |
| `1029_verify_extract_v1.ps1` | 下载 ZIP 后一键核对大小和 SHA-256，校验通过才解压 |

使用完整包只需下载完整包 ZIP、`SHA256SUMS.txt` 和校验脚本三项，放在同一目录。右键使用 PowerShell 运行校验脚本，全部对应大小及 SHA-256 通过后再解压。源码包使用者同样下载源码 ZIP 与这两个校验文件。不把 GitHub 自动生成的 Source code 下载项算进附件清单。

## 首次配置和日常操作

- 仅已列入白名单的群允许处理；私聊默认关闭，默认需 @ 或呼叫机器人。未填写群名单时，首次窗口不允许启动微信桥接。
- 需要更多行为设置，可编辑首次生成的 `config.json` 或在网页中设置。自己的配置和记忆分别保存在 `config.json`、`data/`。
- `反代鲸鲸.cmd` 是控制菜单，包含启动、停止、状态、网页、调试台、备份等入口。`一键终止.bat` 用于停止本项目。
- 仅检查便携环境：`一键部署鲸鲸.cmd -Check`。只用网页：首次不勾选微信桥接，或运行入口加 `-WebOnly`。
- 微信窗口、版本、显示缩放会影响 UI 自动化。真实登录、账号核对和群收发由使用者在自己的设备完成；自检通过不等于已证明所有微信版本都兼容。

## 更新时保留自己的数据

停止本项目后覆盖同一目录，保留原 `config.json` 和 `data/`。发行包不包含这两个运行数据项；首次运行才由使用者生成。不要从别人那里复制含凭据和聊天记录的文件夹。

## 开发

需要 Node 18+。`npm test` 运行离线自动测试；`npm start` 启动网页。微信桥接还需要 Python 3.12 和 `requirements.txt` 所列依赖。完整包已经带好运行环境。

本仓库基于原鲸鲸项目继续整理，保留原 MIT 许可。上游：<https://github.com/Banan1cee/whale_gril>。第三方运行时和模型遵循各自许可，详见 `THIRD_PARTY_NOTICES.md`。发布说明和验收范围见 `docs/1029_公开发布验收_v1.md`。

## 脱敏范围

公开包不含个人模型密钥、账号令牌、Cookie、微信身份、群名单、聊天记忆、日志、数据库、私密截图、ECS/SSH 配置、个人工作草稿或原始 Git 历史。请勿将自己使用后生成的 `data/`、`config.json` 提交到公开仓库。
