# Windows 公开部署版验收

版本 3.53.1，基于本机 Windows 项目制作独立发布副本，未混入 ECS/Linux 配置。

## 已验证

- 451 项离线 JavaScript 测试通过。
- 便携 Node、Python 及 wechatauto、pywin32、psutil、UIA、Pillow、requests 可导入；RapidOCR、ONNX Runtime 和 OpenCV 可导入，OCR 模型文件随完整包。
- PowerShell 脚本语法检查通过。
- 隔离验收中连续执行一键入口两次，监听进程始终一份；未自动打开浏览器页面。
- 网页及 PNG 资源可访问，网页聊天通过本地模拟模型完成完整请求和回复。
- 公开文本已比对本机真实密钥及高风险凭据格式，未检出；没有 data/config.json、私密截图、ECS 草稿或旧 Git 历史进入发布清单。

## 实际边界

首次配置窗口由使用者填写自己的模型、密钥和群白名单，桌面微信由使用者手动登录。验收没有启动真实微信桥接或向任何真实群发送消息，也没有调用用户真实模型额度。不能把运行时导入或网页自检等同于每个微信版本、账号和显示缩放下的真实收发成功。

完整包 ZIP 会在发版前核对目录清单、必需资源、运行时和隐私排除，并从压缩包解压后复核一键环境检查。ZIP 大小与 SHA-256 以 Release 中 SHA256SUMS.txt 为准。

## 与原项目隔离

个人配置、分群记忆、模型凭据和本机原文件保持在使用者自己的目录。公开仓库是全新历史，只包含脱敏副本。不要直接把运行后整个目录上传。
